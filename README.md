# marianna_24501
# Название проекта: Well Logging Classification (Интерактивная классификация данных ГИС по кросс-плотам)

## Отраслевая проблема
При петрофизической интерпретации специалист анализирует сочетания каротажных параметров на кросс-плотах и вручную выделяет группы точек. Результат интерпретации должен быть связан с глубиной и сохранён вместе с исходными каротажными данными.

## Цель проекта
Создание интерактивного desktop-приложения на PySide6 для просмотра каротажных кривых, построения кросс-плотов (crossplots), интерактивного выделения классов точек с помощью полигонов и сохранения новой классификационной кривой в исходный LAS-файл без потери данных.

## Краткое описание функционала
* **Загрузка и визуализация:** Выбор и чтение LAS-файлов, отображение списка доступных кривых и их графиков по глубине.
* **Построение кросс-плотов:** Выбор пар параметров (X и Y) для интерактивного анализа взаимосвязей с фильтрацией NULL-значений.
* **Интерактивная разметка:** Выделение зон на кросс-плоте замкнутыми полигонами, создание классов с числовыми ID и описанием, динамическое присвоение классов точкам внутри полигона.
* **Экспорт результатов:** Формирование результирующей кривой `CLASS` и сохранение её в новый файл формата LAS с полной сохранностью исходных каротажных кривых.

## Используемый стек технологий (Разрешенные библиотеки)
* Python (вычислительное ядро отделено от GUI)
* PySide6 (для создания графического интерфейса пользователя)
* NumPy, Pandas (для быстрой обработки массивов данных и таблиц)
* Lasio (для чтения и записи файлов формата LAS)
* PyQtGraph (для построения интерактивных графиков и кросс-плотов)

## Структура проекта
* `src/` — исходный код вычислительного ядра приложения (чтение, запись LAS, алгоритмы point-in-polygon).
* `notebooks/` — исследовательские ноутбуки (JupyterLab) для проверки гипотез и прототипирования графиков.
* `tests/` — автоматические тесты для проверки корректности алгоритмов классификации.
* `app/` — графический интерфейс пользователя (GUI) на PySide6.
